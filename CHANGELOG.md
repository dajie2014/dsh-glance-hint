# 更新日志 · 览示（Glance-Hint）

## v1.0 — 2026-10-11

**中文**

览示（Glance-Hint）
只读观测层。
收集正在运行任务流当中的各类信号。
不执行写入操作，不介入任务执行，不会自主做出任何判断。
将采集到的运行事件，转换为动画与声音提示交付给操作者。
作为一层可移除的中间夹层存在于人和引擎之间。
需要时启用以获得实况感知，亦可随时关闭，撤除此层观测。

**English**

Glance-Hint
Read-only observation layer.
It collects signals from active task workflows.
It performs no writes, does not intervene in execution, and makes no autonomous decisions.
It converts collected runtime events into animations and audio cues for the operator.
Serves as a removable intermediate layer between human and engine.
Enable it for live awareness, or disable at any time to remove this observation layer.
